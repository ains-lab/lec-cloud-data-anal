# HTML 강의 슬라이드 사용 안내

## 열 파일

[LLM 위키 2장 HTML 슬라이드](llm-wiki-chapter-02-slides.html)

- 본편 32장 + 부록 6장, 총 38장이다.
- 기존 7주차 강의 노트의 쉬운 설명과 가상 실습을 슬라이드로 구성했다.
- 박승규의 『LLM위키 완벽 가이드』 2장에 제공된 **원문 이미지 4개와 표 19개**를 포함한다.[4][5][6]
- 문서 예시의 Markdown 코드 블록 안에 있는 표도 포함한다. 예시의 날짜·건수·기대 효과는 이번 작업의 실제 관측 결과가 아니다.

## 브라우저에서 열기

HTML 파일을 더블 클릭하거나 브라우저의 파일 열기로 연다. 별도 서버, 설치, API 키가 필요 없다.

**이미지·글꼴·CSS·JavaScript가 HTML 안에 들어 있으므로 HTML 한 파일만 복사해도 오프라인 발표가 가능하다.** 원문 출처 링크를 열 때만 인터넷 연결이 필요하다.

처음 열면 발표 보기다. 화면 폭이 좁은 휴대전화에서는 전체 읽기로 전환되며, 긴 표는 표 안에서 좌우로 스크롤할 수 있다.

## 조작

| 조작 | 기능 |
| --- | --- |
| `←` / `→` | 이전 / 다음 슬라이드 |
| `PageUp` / `PageDown` | 이전 / 다음 슬라이드 |
| `Home` / `End` | 첫 / 마지막 슬라이드 |
| 하단 목차 선택 | 원하는 슬라이드로 이동 |
| `R` 또는 전체 읽기 버튼 | 모든 슬라이드를 세로로 읽기 |
| `F` 또는 전체 화면 버튼 | 브라우저가 허용하면 전체 화면 전환 |
| 인쇄 버튼 | 전체 슬라이드 인쇄 |
| `?` 버튼 | 도움말 열기. `Esc`로 닫기 |
| 예시 답 보기 | 해당 확인 문제의 답 펼치기 |

목차 선택 상자처럼 입력을 받는 곳에 포커스가 있으면 슬라이드 단축키 대신 해당 입력의 기본 동작을 유지한다. 브라우저가 로컬 저장을 허용하면 마지막 슬라이드와 보기 모드를 기억한다.

## 인쇄

- 발표 보기와 전체 읽기 모두 **전체 38장**을 인쇄한다.
- 슬라이드 한 장이 인쇄 한 페이지에 대응한다. 16:9 사용자 정의 용지 규격을 사용한다.
- **접혀 있던 예시 답도 인쇄에 포함한다.** 문제지만 배포하려면 답이 함께 출력된다는 점에 유의한다.
- 사용자 브라우저의 머리글·바닥글은 끄는 편이 좋다. 배경 그래픽 옵션을 켜면 슬라이드의 표 색상을 유지하기 쉽다.
- 브라우저의 인쇄 창에서 PDF 저장을 선택할 수 있다. 별도의 PDF를 제출 파일로 만든 것은 아니며, 인쇄 검증용 PDF는 Hermes 캐시에 보관했다.

## 원문을 그대로 사용한 범위

| 대상 | 처리 |
| --- | --- |
| 원문 이미지 | 다운로드한 바이트를 변경하지 않고 HTML에 내장. 자르기·재인코딩·재그리기 없음 |
| 원문 표 | 머리글, 행·열 순서, 셀 문구 유지. HTML 표시 형식과 색상·줄바꿈만 변경 |
| 표 속 코드 표현 | Markdown의 백틱을 HTML의 `code` 표시로 바꿈. 표시되는 코드 문자열은 유지 |
| 쉬운 비유·해설 | 강의용 재구성으로 표시. 원문 표 아래 해설은 표의 일부가 아님 |
| 팀 회의 실습 | 가상 사례이며 실제 회의·모델 출력·실험 성과가 아님 |

각 슬라이드의 출처 링크와 출처 슬라이드에 저자·문서 위치를 표시했다. 원문 자산의 권리를 새롭게 부여하거나 재배포 조건을 판정한 자료는 아니다. 공개 재배포 전에는 원전의 표시 조건을 확인한다.

## 보존·수정·검증 파일

- `assets/source-images.json`: 원문 이미지 URL, 파일 위치, 크기, SHA-256.
- `assets/source-tables.json`: 원문 표의 머리글, 행, 셀, 원문 Markdown.
- `slides-content.json`: 슬라이드 순서와 강의용 설명.
- `slides-template.html`: 화면·인쇄 스타일과 브라우저 조작.
- `build_slides.py`: 표와 이미지 원본을 넣어 HTML을 생성하는 표준 라이브러리 전용 빌더.
- `test_slides.py`: 모든 원문 표 셀과 이미지 해시를 대조하는 회귀 검사.
- `slides-provenance.json`: 생성된 HTML의 해시, 장수, 출처 대응.
- `slides-verification.json`: 실제 브라우저·인쇄 검사와 미완료 검토 경계.
- `assets/fonts/OFL.txt`: 내장한 Noto Sans KR 글꼴의 SIL Open Font License 1.1. 라이선스는 HTML 주석에도 들어 있다.[7]

내용을 고칠 때는 생성된 HTML을 직접 고치지 않고 JSON이나 템플릿을 수정한다. 저장소 루트에서 다음 명령으로 다시 생성하고 원문 보존 검사를 실행한다.

```bash
python3 docs/lectures/7w/slides/test_slides.py
```

이 명령은 실제로 HTML과 생성 출처 기록을 다시 쓴다. 브라우저 레이아웃과 인쇄 검사는 자동으로 갱신하지 않으므로, 변경 후에는 다시 점검해야 한다. **검증 기록의 HTML 해시와 현재 HTML 해시가 다르면 이전 검증을 최신 결과로 사용하지 않는다.**

강의 문구를 추가하면 글꼴에 새로운 글자가 필요할 수 있다. 내장 서브셋의 글자 범위와 실제 브라우저 글꼴을 다시 확인하고 필요하면 글꼴을 갱신한다.

## 검증 경계

원본 이미지의 파일 해시와 디코딩·로딩은 확인할 수 있지만, 이미지 안의 글자·도해 의미를 사람이 읽고 승인한 것과는 다르다. 이번 시각 검토 도구는 `Gemini HTTP 403 PERMISSION_DENIED`로 실패했다. **시각·의미 검토는 미완료이며, 실제 수행한 DOM 배치·기능·인쇄 검증과 구분한다.**

## 폴더 이동 기록
