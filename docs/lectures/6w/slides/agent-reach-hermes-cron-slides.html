저장과 식별

같은 자료는 ID로 구분한다

아래 장부·스키마는 강의의 설계 제안이며 도구의 내장 기능이 아니다

중복 키

platform · type · id

ID는 문자열로 저장한다.
Reddit 글·댓글의 fullname을 구분한다.
제목·URL만으로 중복을 판단하지 않는다.

같은 콘텐츠를 여러 검색에서 발견하면
콘텐츠 하나 + 발견 경로 여러 개.

최소 기록
  • ID · 작성자/채널 · 원문 URL
  • 게시 시간과 실제 시간 정밀도
  • 수집 시각 · backend 버전 · run ID
  • 출처 스냅샷 · 누락 가능성

본문 버전과 좋아요·조회 수 관측값은 분리한다.
개인 비공개 데이터는 강의 Git 밖에 둔다.

Hermes Cron

실행 모드와 새 세션을 이해한다

예약 작업은 현재 대화를 기억한다고 가정하지 않는다

Agent 작업

새 세션에서 프롬프트·문서를 읽는다.
도구 호출과 처리 흐름을 학습한다.
모델 비용·실행 편차를 검토한다.

절대 workdir·정책·RUNBOOK·
실패 조건을 명시한다.

Script-only 작업

이미 구현·검증된 수집기를 실행한다.
script + no_agent: true
실패는 nonzero 종료 코드로 보고한다.

script만 지정하면 agent가 이어질 수 있다.
no_agent 작업은 프롬프트로 수집기를 만들어 주지 않는다.

스킬을 로드해도 새로운 인증·이용 권한이 생기지 않는다.
