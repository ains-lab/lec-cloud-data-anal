# 6주차 · SNS 수집 자동화 핵심 요약 슬라이드

`agent-reach-hermes-cron-slides.html`을 브라우저로 연다. 20장의 핵심 요약본이며 글꼴·CSS·JavaScript를 내장해 오프라인으로 표시된다. 원문 문서 링크는 상위 6w 자료 폴더를 함께 보관해야 열린다.

## 구성

역할 구분 → 승인한 수집 범위 → 인증·실행 환경 → X·Reddit·YouTube 차이 → 출력·ID·시간 계약 → 중복·안전 저장 → 실패 상태 → Cron 모드·일회 시험 → 일정·알림 → 장애·보안 → 핵심 점검.

긴 명령, 전체 설치 절차, 계정 목록, 긴 설정 JSON은 생략했다. 다이어그램과 표는 핵심을 요약한 재구성이다. 세부 명령과 정책 근거는 슬라이드 하단과 마지막 페이지의 원문 문서를 따른다.

## 조작

- ← / → 또는 PageUp / PageDown: 슬라이드 이동
- Home / End: 처음·마지막
- R: 전체 읽기, F: 전체 화면
- 선택 메뉴: 원하는 슬라이드 이동
- 모바일: 전체 읽기 자동 전환
- 핵심 점검의 예시 답: 펼쳐 보기
- 인쇄: 전체 슬라이드 및 접힌 예시 답 포함

## 자료·검증 경계

기존 6주차 문서의 확인 기준은 2026-10-04 UTC다. 슬라이드 생성 과정에서 SNS 접속·로그인·도구 설치·쿠키 열람·Cron 등록·gateway 변경·수집기 실행·외부 알림은 하지 않았다. 도구 예시는 현재 설치에서 반드시 동일하게 동작한다는 보장이 아니다.

- `slides-content.json`: 요약 내용과 슬라이드 순서
- `slides-provenance.json`: 원문10개 및 HTML 해시, 출처·글꼴 기록
- `slides-verification.json`: 실제 수행한 정적·브라우저 검사와 미완료 항목

화면 검사와 데이터 수집 성공은 별개다. 픽셀 검토 도구의 사용 가능 여부도 검증 기록에 따로 기록한다.
