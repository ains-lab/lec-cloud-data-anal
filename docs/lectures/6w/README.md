# 6주차 — Agent Reach와 Hermes Cron으로 SNS 수집 자동화하기

**X·Reddit·YouTube에서 키워드 또는 승인한 계정·채널을 기준으로 자료를 찾고, Hermes의 예약 작업으로 반복하는 방법**을 다룬다.

Agent Reach는 사이트별 **수집 도구 상자**, Hermes Cron은 **알람 시계**, 저장 상태는 **어디까지 모았는지 적은 장부**다. 알람이 울렸다는 사실과 자료를 제대로 저장했다는 사실은 다르다.

## 대상과 범위

- 대상: 터미널·JSON·Hermes 기초를 배운 학부 수강생. 먼저 쉬운 비유로 설명하고 실제 명령·운영 조건을 덧붙인다.
- 형식: 주제별 한국어 기술문서. Linux/Bash 명령을 기준으로 한다.
- 작성 기준: 2026-10-04 UTC. 공식 문서와 설치된 CLI의 help·소스를 대조했다. 버전과 검증 경계는 [마지막 문서](08-operations-and-verification.md)에 기록한다.
- **문서 작성만 수행했다.** 패키지 설치, 로그인, 쿠키 열람, 실제 SNS 조회, Cron 등록·실행, 외부 알림은 하지 않았다.
- 이 자료는 완성된 수집 프로그램 배포가 아니다. 제공하는 것은 명령 조합, 데이터 계약, 자급적인 Cron 프롬프트와 등록·검증 절차다. 운영용 script-only 수집기는 별도 구현·검증 대상이다.

## 수업에서 완성할 수 있는 것

1. 수집 목적과 플랫폼별 키워드·watchlist를 정한다.
2. 허용된 플랫폼 하나에서 적은 수의 결과를 수동 조회하고 파일·상태를 검사한다.
3. 같은 작업을 한 번 더 실행해 중복 방지와 실패 처리를 확인한다.
4. 검증된 작업만 Hermes Cron에 정지 상태로 등록한다.
5. 일회 실행의 데이터 결과까지 확인한 뒤 반복 실행을 승인한다.

인증·정책 승인이 없는 수강생은 **명령 help 확인과 설계 검토까지만** 진행한다. 특히 Reddit의 연구 이용은 [정책 확인](04-reddit-collection.md)이 선행되어야 한다. 로그인에 성공했다는 이유로 연구용 수집 권한이 생기지 않는다.

## 먼저 바로잡을 오해

| 오해 | 정확한 설명 |
| --- | --- |
| `agent-reach search`로 모든 SNS를 검색한다 | 실제 조회는 플랫폼별 upstream CLI가 맡는다. 없는 통합 명령을 만들지 않는다. |
| 팔로워를 읽으면 내가 구독한 사람들의 글이 나온다 | followers와 following의 방향은 반대다. YouTube 구독 채널은 또 다른 개념이다. |
| 공개 글이면 인증 없이 무제한 수집 가능하다 | 인증·서비스 정책·호출 제한·지역·IP 조건이 각각 적용된다. |
| `-n 100`이면 정확히 100건이며 전체 자료다 | 요청 상한일 뿐, 검색 누락·페이지 제한·삭제가 있을 수 있다. |
| Cron 등록 성공이면 수집 성공이다 | scheduler 실행, 인증, 파일 저장, 데이터 검증, 알림을 따로 확인해야 한다. |
| 로컬 Cron이 나중에 이 TUI에 메시지를 띄운다 | `deliver: local`은 로컬 결과 저장이다. 별도 연결된 알림 채널 없이는 원격 통지도 없다. |
| 무료 CLI라서 운영 비용이 없다 | 모델 호출·서버·저장·허용된 서비스 이용 비용은 별개다. |

## 기존 강의와의 관계

- [5주차 Agent Reach 소개](../5w/social-collection-agent-reach.md)를 자동화 운영 관점으로 확장한다. 과거 문서의 무인증·무료·설치 예시는 최신 인증 조건과 다를 수 있으므로 이번 자료의 버전별 확인을 우선한다.
- [4주차 자료](../4w/README.md)는 별도 API 수집기·SQLite·Wiki 실습이다. 해당 토큰·프로그램·스키마를 Agent Reach CLI에 그대로 연결하지 않는다.
- 저장소 루트의 [AGENTS.md](../../../AGENTS.md)와 [SCHEMA.md](../../../SCHEMA.md)는 **별도 arXiv HTML 논문 Wiki 계약**이다. SNS 자료를 루트 `raw/`, `_meta/`, 지식 페이지에 넣지 않고 기존 논문 Cron도 변경하지 않는다.
- 실행용 정책·결과·상태·인증정보는 강의 Git 저장소 밖에 둔다. 이 폴더에 예시를 작성한 것은 운영 환경 생성이나 자동화 활성화가 아니다.
