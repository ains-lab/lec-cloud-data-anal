## 학습자 가정과 수업 운영

- 대학생이며 LLM 대화와 기본 파일·폴더 조작을 경험했다고 가정한다. 계정, 유료 API, 특정 운영체제나 도구 설치를 슬라이드 열기의 전제로 삼지 않는다.
- 공통 사례는 가상의 학생 팀 프로젝트다. 실제 학생 개인정보·고객 자료·비공개 연구 원문을 외부 모델에 보내는 활동이 아니다.
- 학습 목표 → 개념 설명 → 원문 삽화·표 → 사례·반례 → 확인 질문 → 실습·제출 기준 → 정리로 진행한다. 보조 원문 표는 부록에서 선택할 수 있다.
- 도구를 사용할 수 없는 학생은 종이나 텍스트 편집기로 동일한 역할 분류, 문서 설계, 근거 대조 결과를 제출한다. 실제 모델 실행을 수행하지 않았다면 실행 결과로 표기하지 않는다.
- 실습의 제안 시간과 예시 답은 운영 설계이며, 수업 시범 운영이나 학습 효과를 측정한 결과가 아니다.

## HTML 사용

각 주차의 `slides/llm-wiki-chapter-NN-slides.html`을 브라우저에서 연다. HTML 하나에 이미지·글꼴·CSS·JavaScript를 내장했으므로 슬라이드 열기에는 네트워크가 필요하지 않다. 마지막 출처 페이지와 하단 링크를 통해 원전으로 이동할 때만 인터넷이 필요하다.

- ← / → 또는 PageUp / PageDown: 이동, Home / End: 처음·마지막.
- R: 전체 읽기, F: 전체 화면, 선택 메뉴: 원하는 슬라이드로 이동.
- 모바일: 전체 읽기, 긴 표: 표 안에서 가로 스크롤.
- 예시 답: 펼쳐 보기. 인쇄: 전체 슬라이드와 예시 답 포함.
- 마지막 위치는 브라우저의 localStorage에 주차별로 저장한다. 저장이 허용되지 않아도 표시와 이동은 동작하도록 되어 있다.

## 원문 보존과 추가 설명

- 조회한 원문 페이지 29개, 삽화 29개, 표·문서 예시 표 132개를 각 주차 `assets/`에 기록했다.
- 삽화의 원본 파일 바이트는 변경하지 않고 base64로 HTML에 내장했다. 비율을 유지하여 표시하며 이미지를 새로 생성하거나 OCR로 재작성하지 않았다.
- 표는 머리글, 행 순서, 셀 문구를 유지했다. 인라인 코드의 백틱만 HTML `<code>` 서식으로 표시한다. 긴 표는 행을 나누고 원문 머리글을 반복한다. 셀 생략이나 요약은 하지 않는다.
- 원문의 코드·문서 예시 안에 있는 표도 포함한다. 해당 값은 실제 수업 수행 결과나 실험 성과가 아니다.
- 출처는 각 슬라이드의 클릭 가능한 숫자 링크와 마지막 출처 페이지에 표시한다. 앞서 제거 요청한 삽화별 반복 캡션은 생성하지 않는다.
- 쉬운 설명, 워크플로우 재구성, 학생 가상 사례는 원전 자산과 구분한다. 추출본에 남아 있는 Mermaid 코드만 `source-diagrams.json`에 보존했으며, 모든 원전 도해를 픽셀 동일하게 렌더링했다고 주장하지 않는다.
- `assets/sources/*.md`는 WikiDocs 본문의 실제 웹 추출본이다. 원본 HTML이라고 표시하지 않는다. 직접 HTTP와 원전 브라우저 접근은 Cloudflare에 막혔고, 본문 조회는 웹 추출 도구를 사용했다.
- 원전 출처 표시는 자료 이용 허가의 모든 조건을 대체하지 않는다. 교육 범위를 넘어 외부에 재배포·상업적 이용할 경우 원전 이용 조건과 별도 권리 관계를 확인한다.

## 재생성과 검사

저장소 루트에서:

```sh
python3 docs/lectures/llm-wiki-course/build_course.py
python3 -m unittest discover -s docs/lectures/llm-wiki-course -p 'test_course.py' -v
```

특정 주차만 재생성하려면 `build_course.py --week 9`처럼 사용한다. 빌더와 보존 검사는 Python 표준 라이브러리만 사용하며 네트워크·모델 호출은 없다. 해당 HTML과 `slides-provenance.json`을 다시 쓴다.

- `slides-content.json`: 수정할 강의 설명과 순서.
- `slides-provenance.json`: 생성된 HTML 해시, 슬라이드별 출처와 자산 목록.
- `source-images.json`: 실제 원문 이미지 URL·파일 SHA-256·크기.
- `source-tables.json`: 원문 표 문구와 순서.
- 공통 `citations.json`: 조회 때 등록한 출처 번호. 여러 장에서 동일한 번호가 동일한 URL을 가리킨다.
- 공통 `assets/fonts.json`, `assets/OFL.txt`: 실제 다운로드한 한글 글꼴과 SIL Open Font License 1.1.
- 공통 `verification.json`: 실제 테스트·브라우저 검사와 미완료 검토를 구분한 기록.

표·이미지 보존 테스트 통과는 모든 주장의 진실성, 전체 시각 품질, 접근성 인증, 학생의 학습 성취를 증명하지 않는다. 실제 검증한 화면 크기와 상태, 미완료 항목은 `verification.json`을 따른다.
